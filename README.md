# Svaston VPN subscription

Workflow публикует **только фиксированный список** из `manual_nodes.txt` — 8 URI, переданных владельцем. Сбор Telegram и сторонних GitHub-фидов отключён, поэтому старые и случайные узлы не должны возвращаться в подписку.

## Как работает

- Каждый час GitHub Actions читает `manual_nodes.txt` и формирует подписку.
- Xray и официальный Hysteria-клиент выполняют диагностический HTTPS-запрос через туннель для всех 8 записей.
- В ручном режиме вывод сохраняет все URI из файла, даже если часть не ответила из GitHub Actions. `out/meta.json` показывает результаты пробника; успешная проверка на runner не гарантирует доступность из телефона и наоборот.
- Hysteria2 URI с завершающим `/` корректно разбираются, а HTML-сущности `&amp;` в исходных ссылках перед разбором декодируются.

## Выходные файлы

| Путь | Назначение |
|---|---|
| `out/sub/b64.txt` | Base64-подписка для INCY |
| `out/sub/combined.txt` | Тот же список обычным текстом |
| `out/meta.json` | Источник, результаты туннельных проб и проверка структуры |
| `out/singbox/config.json` | Конфиг sing-box |
| `out/clash/config.yaml` | Конфиг Clash |

Raw-ссылки после обновления workflow:

```text
https://raw.githubusercontent.com/WWanderAI/svaston-vpn/main/out/sub/b64.txt
https://raw.githubusercontent.com/WWanderAI/svaston-vpn/main/out/sub/combined.txt
```

## Безопасность

Репозиторий публичный. Любой человек, у которого есть raw-ссылка, сможет скачать URI и использовать содержащиеся в них UUID/пароли. Публикуйте только те серверные доступы, которыми разрешено делиться; расход лимита или блокировка аккаунта у оператора могут затронуть владельца конфигов.

## Локальная проверка

```bash
pip install -r requirements.txt
python main.py --manual-nodes-file manual_nodes.txt
python tests/selftest.py
```

Для туннельной проверки локально установите Xray и Hysteria и задайте `XRAY_BIN` и `HYSTERIA_BIN`. Сам факт генерации подписки не подтверждает, что каждый сервер подключится в конкретной сети или на конкретном телефоне.
