# Svaston VPN Aggregator

Сборщик **бесплатных публичных** VPN-конфигураций с фильтром реального подключения. Проект не покупает серверы и не использует закрытые учётные данные Telegram.

## Источники

1. Публичная веб-страница Telegram `https://t.me/s/<username>` — только сообщения за последние 24 часа. Никакого входа в Telegram, `api_id`/`api_hash` или bot token.
2. [MatinGhanbari/v2ray-configs — super-sub](https://raw.githubusercontent.com/MatinGhanbari/v2ray-configs/main/subscriptions/v2ray/super-sub.txt).
3. [barry-far/V2ray-Config — общий base64-фид](https://raw.githubusercontent.com/barry-far/V2ray-Config/main/All_Configs_base64_Sub.txt).

GitHub-фиды общедоступны и могут содержать тысячи URI. Большой список равномерно сокращается до `FREE_FEED_NODE_CAP` конфигураций; затем общий пул дедуплицируется. Поддерживаются только HTTPS-ссылки на `raw.githubusercontent.com`; TLS-сертификат при скачивании проверяется.

## Проверка и публикация

Каждый час GitHub Actions собирает кандидатов и проверяет выборку до 200 узлов. Открытый TCP-порт не считается доказательством работы: Xray или официальный Hysteria-клиент поднимает локальный прокси, после чего выполняется настоящий HTTPS-запрос **через туннель**. Публикуются не более 20 самых быстрых из реально ответивших узлов: не более 800 мс и не более чем на 600 мс медленнее лучшего узла текущей выборки. Если меньше 20 проходят проверку, выдаётся меньше 20 — непроверенные конфиги не добавляются.

Проверка с GitHub Actions не может гарантировать подключение именно с телефона: маршруты и блокировки различаются по стране, провайдеру и сети. Публичные конфигурации могут отключиться до следующего обновления, а оператор бесплатного сервера неизвестен. Не передавайте через такие узлы пароли, банковские данные и другую чувствительную информацию.

Если проверка не нашла ни одного подтверждённого узла, предыдущая публикация не перезаписывается. Состояние запуска и счётчики доступны в `out/meta.json`.

## Выходные файлы

| Путь | Назначение |
|---|---|
| `out/sub/b64.txt` | Base64-подписка с проверенными узлами |
| `out/sub/combined.txt` | Те же URI в обычном текстовом виде |
| `out/singbox/config.json` | Конфиг sing-box |
| `out/clash/config.yaml` | Конфиг Clash |
| `out/meta.json` | Источники, статистика проверки и валидация |

URL после публикации (замените `OWNER/REPO` на адрес своего репозитория):

```text
https://raw.githubusercontent.com/OWNER/REPO/main/out/sub/b64.txt
https://raw.githubusercontent.com/OWNER/REPO/main/out/sub/combined.txt
https://raw.githubusercontent.com/OWNER/REPO/main/out/singbox/config.json
https://raw.githubusercontent.com/OWNER/REPO/main/out/clash/config.yaml
```

## Настройка и запуск

Workflow использует встроенный `GITHUB_TOKEN`; PAT не нужен для обычного запуска Actions. Источники фидов задаются в `FREE_FEEDS`, а ограничение числа URI на один фид — в `FREE_FEED_NODE_CAP`. Пример есть в `.env.example`.

Для локального сбора:

```bash
pip install -r requirements.txt
cp .env.example .env
# При необходимости измените TG_CHANNEL в .env
python main.py --channel halyava_vpnz
```

Для полного локального туннельного теста установите Xray и Hysteria и укажите пути через `XRAY_BIN` и `HYSTERIA_BIN`. Без тестового клиента узлы считаются непроверенными и не публикуются.

Офлайн-тесты парсера и генератора:

```bash
python tests/selftest.py
```

## Частые причины пустой/неработающей подписки

- Публичный узел уже отключён или его данные заменились в источнике.
- Узел работает из GitHub Actions, но недоступен с конкретной мобильной сети.
- Клиент не поддерживает протокол или параметры конкретной ноды.
- Пользователь импортировал устаревшую копию вместо URL-подписки, которая обновляется.

Поэтому публичные бесплатные конфиги — временный вариант, а не гарантия стабильного VPN.
